# AGENTS.md

Working guidelines for this repository.

## Session log

Only create a session log when the user explicitly asks for it. When requested, record
the session in a new Markdown file inside `docs/sessions/`.

- File name: `NNNN_descriptive_slug_ES.md` (4 digits, zero-padded, incremental). Session
  logs are written in **Spanish**, so the name always ends with `_ES.md`.
  Example: `0001_setup_project_ES.md`, `0002_flutter_scaffold_ES.md`.
- It must explain **what we did**, the **code that was touched**, and anything relevant,
  so it can be read later to review the work and the code.
